## اجرا
```
pip install "setuptools<58" wheel && pip install --no-build-isolation semopy==2.3.11
pip install pandas numpy scipy statsmodels scikit-learn shap matplotlib arabic-reshaper python-bidi openpyxl
OMP_NUM_THREADS=1 python code/paper1_analysis.py   # حدود ۴ دقیقه
OMP_NUM_THREADS=1 python code/paper2_analysis.py   # حدود ۱۵ دقیقه
python code/build_paper1.py && python code/build_paper2.py
```
`OMP_NUM_THREADS=1` اجرا را به‌شدت سریع‌تر می‌کند (بازنمونه‌گیری‌های پرتکرار).

## هشدارهای مهم
1. **داده‌ها شبیه‌سازی‌شده‌اند** (دو نمونهٔ مستقل: ۳۸۶ و ۴۴۲ نفر). اعداد، توان روش در بازیابی ساختار مفروض را نشان می‌دهند، نه شواهد دربارهٔ بازار. برای ارسال به مجله به‌عنوان مطالعهٔ تجربی باید پرسشنامه را اجرا و کد را روی داده‌ٔ واقعی (`DATA_PATH`) بزنید و بخش‌های یافته/بحث را بازنویسی کنید.
2. **منابع:** مشخصات منابع لاتین از حافظه نوشته شده‌اند؛ **همهٔ DOIها را پیش از ارسال با Crossref بررسی کنید.** تنها یک منبع فارسی (حیدری هراتمه و همکاران، ۱۴۰۲) از طریق جست‌وجو تأیید شد؛ DOI آن و منابع فارسی بیشتر باید توسط نویسنده تکمیل شود (در فایل با هایلایت زرد مشخص شده‌اند).
3. **قالب Word:** فایل‌ها از نظر ساختار با python-docx بررسی شدند، اما در Word/LibreOffice رندر نشده‌اند (LibreOffice در محیط ساخت کار نمی‌کرد). پیش از ارسال، فایل را در Word باز کنید؛ فونت‌های B Nazanin و B Zar باید نصب باشند.
4. **متن عنوان/نویسنده:** نام، وابستگی سازمانی و ایمیل جایگزین (هایلایت زرد) شده‌اند.
5. **اگر هر دو مقاله از یک پیمایش واقعی بیایند** باید در هر دو افشا و به یکدیگر ارجاع شود (تقسیم‌ناپذیر به «برش سالامی» نشود).
